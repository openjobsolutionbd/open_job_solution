# বানান চেকার — উৎস ও লাইসেন্স তথ্য

## ডিকশনারি লেয়ার
1. **bn (@cspell/dict-bn)** — সাধারণ বাংলা ওয়ার্ডলিস্ট (MinhasKamal/BengaliDictionary সোর্স)
2. **known-words.txt** — এই প্রজেক্টের নিজস্ব curated হোয়াইটলিস্ট, bcs-mcq/data/-এর বিদ্যমান সঠিক কনটেন্ট থেকে সিড করা এবং প্রতিটা নতুন সঠিক শব্দ ম্যানুয়ালি যোগ হয়ে বাড়ে
3. **prothomalo-words.txt** — প্রথম আলোর অফিসিয়াল নিউজপেপার কর্পাস (১ কোটি টোকেন, প্রথম আলো কর্তৃক প্রকাশিত, Mozilla Data Collective-এ হোস্টেড) থেকে বের করা শব্দ, শুধু যেগুলো কমপক্ষে ৩ বার এসেছে (বিরল/টাইপো ফিল্টার করার জন্য)
