# verified-facts.md — ওয়েবে যাচাই-করা তথ্যের খাতা

**উদ্দেশ্য:** একই তথ্য বারবার সার্চ না করা। কোনো সময়-সংবেদনশীল তথ্য (বর্তমান পদধারী, সংখ্যা, র‍্যাংকিং, সাম্প্রতিক ঘটনা) সার্চ করার **আগে** এখানে দেখুন; যাচাই করলে **পরে** এখানে যোগ বা হালনাগাদ করুন।

**ব্যবহারের নিয়ম** (সংক্ষেপে, বিস্তারিত `_docs/AGENTS.md`-এ):
1. "পুনর্যাচাই" তারিখ পেরোয়নি এবং প্রশ্নটা ঠিক এই তথ্য নিয়ে হলে — নতুন সার্চ না করে এখানকার তথ্য ব্যবহার করুন।
2. "পুনর্যাচাই" তারিখ পেরিয়ে গেলে বা সন্দেহ থাকলে — আবার সার্চ করে সারি হালনাগাদ করুন (পুরনো সারির নিচে জমা না করে, সেই সারিই বদলান)।
3. এখানে শুধু **যাচাই-করা** তথ্য যায়। সূত্রে না-পাওয়া বা অনুমান এখানে লিখবেন না — "অযাচাই" অংশে যাবে।
4. পরীক্ষার প্রশ্ন বছর-নির্দিষ্ট হলে (যেমন "২০২৫-২৬ অর্থবছরের বাজেট কত?") উত্তর সেই বছরের তথ্যই থাকবে, এখানকার সর্বশেষ তথ্য দিয়ে বদলাবেন না।
