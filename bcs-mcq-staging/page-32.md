প্রশ্ন ৭৫. যদি 0 < x < 1 হয়, তবে নিচের কোনটি সবচেয়ে বড় হবে?

ক) x    খ) 2x    গ) x²    ঘ) x + 1

সঠিক উত্তর: ঘ) x + 1

Live MCQ Analytics: Right: 56%; Wrong: 14%; Unanswered: 28%; [Total: 27459]

সমাধান:
দেওয়া শর্তে, 0 < x < 1 → সবচেয়ে বড় মান হবে ঘ) x + 1
ধরি,
x = 0.5 (0 থেকে 1-এর মধ্যে যেকোনো মান নিলেই একই ফলাফল আসবে)
অপশন ক) x = 0.5
অপশন খ) 2x = 2 × 0.5 = 1.0
অপশন গ) x² = (0.5)² = 0.25
অপশন ঘ) x + 1 = 0.5 + 1 = 1.5
তুলনা করে পাই, 1.5 > 1.0 > 0.5 > 0.25
⇒ x + 1 > 2x > x > x²
সুতরাং, ঘ) x + 1 সবচেয়ে বড় হবে।

ধরি,
y = √x + (1/√x)
⇒ y² = {√x + (1/√x)}²
⇒ y² = (√x)² + 2 × √x × (1/√x) + (1/√x)² ; [(a + b)² = a² + 2ab + b²]
⇒ y² = x + 2 + (1/x)
⇒ y² = x + (1/x) + 2
⇒ y² = 0 + 2
⇒ y² = 2
∴ y = ± √2
∴ √x + (1/√x) = √2

প্রশ্ন ৭৬. - 1 + 1/2 - 1/4 + 1/8 - 1/16 + ... অসীম ধারাটির যোগফল হবে:

ক) - 2/3    খ) - 3/2    গ) 2/3    ঘ) 3/2

সঠিক উত্তর: ক) - 2/3

Live MCQ Analytics: Right: 34%; Wrong: 10%; Unanswered: 54%; [Total: 27459]

সমাধান:
এটি একটি গুণোত্তর ধারা।
যার,
১ম পদ, a = - 1
এবং সাধারণ অনুপাত, r = (1/2)/(- 1) = - 1/2 ; r < 1
আমরা জানি,
অসীম ধারাটির যোগফল, S = a/(1 - r) ; [r < 1]
= (- 1)/{1 - (- 1/2)}
= (- 1)/(1 + 1/2)
= (- 1)/(3/2)
= - 1 × (2/3)
= - 2/3
সুতরাং, অসীম ধারাটির যোগফল - 2/3 হবে।

প্রশ্ন ৭৮. সেট {2, 3, 4} এর প্রকৃত উপসেট কয়টি:

ক) 3    খ) 7    গ) 8    ঘ) 9

সঠিক উত্তর: খ) 7

Live MCQ Analytics: Right: 59%; Wrong: 19%; Unanswered: 21%; [Total: 27459]

সমাধান:
প্রকৃত উপসেট (proper subset): কোনো সেট থেকে গঠিত উপসেটের মধ্যে যে উপসেটগুলোর উপাদান সংখ্যা প্রদত্ত সেটের উপাদান সংখ্যা অপেক্ষা কম এদেরকে প্রকৃত উপসেট বলে। যেমন, A = {3, 4, 5, 6} এবং B = {3, 5} দুইটি সেট।
এখানে, B এর সব উপাদান A সেটে বিদ্যমান এবং B সেটের উপাদান সংখ্যা A সেটের উপাদান সংখ্যা থেকে কম।
∴ B, A এর একটি প্রকৃত উপসেট এবং B ⊂ A লিখে প্রকাশ করা হয়।
দেওয়া সেট,
A = {2, 3, 4}
A এর উপাদান সংখ্যা, n(A) = 3
আমরা জানি,
প্রকৃত উপসেট = 2ⁿ - 1
= 2³ - 1
= 8 - 1
= 7
সুতরাং, সেট {2, 3, 4} এর প্রকৃত উপসেট 7টি।
