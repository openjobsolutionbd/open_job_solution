## বর্তমান তথ্য

বর্তমান মন্ত্রিসভায় প্রধানমন্ত্রী তারেক রহমানসহ ২৬ জন পূর্ণ মন্ত্রী এবং ২৩ জন প্রতিমন্ত্রী রয়েছেন (মোট ৪৯ জন)।

সাম্প্রতিক দপ্তর পুনর্বণ্টন (মার্চ ২০২৬):

| নাম | মন্ত্রণালয়/বিভাগ |
|---|---|
| **মন্ত্রী** | |
| আহমেদ আযম খান | মুক্তিযুদ্ধ বিষয়ক মন্ত্রণালয় |
| মো. আমিন উর রশিদ | মৎস্য ও প্রাণিসম্পদ এবং কৃষি মন্ত্রণালয় |
| **প্রতিমন্ত্রী** | |
| মো. শরীফুল আলম | বস্ত্র ও পাট মন্ত্রণালয় |
| সুলতান সালাউদ্দিন টুকু | মৎস্য ও প্রাণিসম্পদ মন্ত্রণালয় |
| হাবিবুর রশিদ | রেলপথ মন্ত্রণালয় এবং সড়ক পরিবহন ও মহাসড়ক বিভাগ |
| মো. রাজিব আহসান | নৌপরিবহন মন্ত্রণালয় এবং সেতু বিভাগ |
| মো. জোনায়েদ আব্দুর রহিম সাকি | পরিকল্পনা মন্ত্রণালয় |
| ফারজানা শারমীন | সমাজকল্যাণ মন্ত্রণালয় |
| মো. নুরুল হক | প্রবাসী কল্যাণ ও বৈদেশিক কর্মসংস্থান মন্ত্রণালয় |
| ববি হাজ্জাজ | প্রাথমিক ও গণশিক্ষা মন্ত্রণালয় |
| মীর মোহাম্মদ হেলাল উদ্দিন | ভূমি মন্ত্রণালয় এবং পার্বত্য চট্টগ্রাম বিষয়ক মন্ত্রণালয় |
| মো. আব্দুল বারী | জনপ্রশাসন এবং খাদ্য মন্ত্রণালয় |
| **উপদেষ্টা** | |
| নজরুল ইসলাম খান | রাজনৈতিক উপদেষ্টা এবং উপদেষ্টা, কৃষি মন্ত্রণালয় |
| রুহুল কবীর রিজভী আহমেদ | রাজনৈতিক উপদেষ্টা এবং উপদেষ্টা, শিল্প মন্ত্রণালয় |
| ডা. জাহেদ উর রহমান | পলিসি ও স্ট্র্যাটেজি, তথ্য ও সম্প্রচার এবং সংস্কৃতি বিষয়ক মন্ত্রণালয় |
