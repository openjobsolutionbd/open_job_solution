## বর্তমান তথ্য

২১ আগস্ট ২০২৬ মন্ত্রী ও প্রতিমন্ত্রীর দপ্তর পুনর্বণ্টন করা হয়। বর্তমানে মন্ত্রিসভায় প্রধানমন্ত্রী তারেক রহমানসহ ২৭ জন পূর্ণ মন্ত্রী এবং ২৩ জন প্রতিমন্ত্রী রয়েছেন। এর মধ্যে ৪ জন টেকনোক্র্যাট মন্ত্রী।

### মন্ত্রণালয়/বিভাগ পুনর্বণ্টন

| নাম | মন্ত্রণালয়/বিভাগ |
|---|---|
| **মন্ত্রী** | |
| ড. আবদুল মঈন খান | স্থানীয় সরকার, পল্লী উন্নয়ন ও সমবায় মন্ত্রণালয় |
| এম রশিদুজ্জামান মিল্লাত | বেসামরিক বিমান পরিবহন ও পর্যটন মন্ত্রণালয় |
| সাচিং প্রু জেরী | পার্বত্য চট্টগ্রাম বিষয়ক মন্ত্রণালয় |
| আন্দালিভ রহমান (পার্থ) | তথ্য ও সম্প্রচার মন্ত্রণালয় |
| আফরোজা খানম | বেসামরিক বিমান পরিবহন ও পর্যটন মন্ত্রণালয় |
| **প্রতিমন্ত্রী** | |
| হুমায়ুন কবির (টেকনোক্র্যাট) | পররাষ্ট্র মন্ত্রণালয় |
| মোহাম্মদ শামীম কায়সার | ধর্ম বিষয়ক মন্ত্রণালয় |
| **উপদেষ্টা** | |
| জহির উদ্দিন স্বপন | রাজনৈতিক উপদেষ্টা |
