## বর্তমান তথ্য

জাতীয় সংসদের স্থায়ী কমিটির সংখ্যা ৫০টি। এর মধ্যে বিষয়ভিত্তিক কমিটি ১১টি এবং মন্ত্রণালয় সম্পর্কিত ৩৯টি। কমিটির ভূমিকা সম্পর্কে দেখুন [[parliamentary-committee]]।

## বিষয়ভিত্তিক কমিটি

| স্থায়ী কমিটি | সভাপতি |
|---|---|
| সরকারি হিসাব সম্পর্কিত | আবদুল্লাহ মোহাম্মদ তাহের (কুমিল্লা-১১) |
| লাইব্রেরি | ব্যারিস্টার কায়সার কামাল (নেত্রকোনা-১) |
| সরকারি প্রতিশ্রুতি সম্পর্কিত | এ এম মাহবুব উদ্দিন খোকন (নোয়াখালী-১) |
| বেসরকারি বিল ও বেসরকারি সদস্যদের সিদ্ধান্ত-প্রস্তাব সম্পর্কিত | মো. শাহজাহান (নোয়াখালী-৪) |
| সংসদীয় | নূরুল ইসলাম মনি (বরগুনা-২) |
| সরকারি প্রতিষ্ঠান সম্পর্কিত সংসদীয় | নূরুল ইসলাম মনি (বরগুনা-২) |
| কার্য উপদেষ্টা | হাফিজ উদ্দিন আহমদ (ভোলা-৩) |
| কার্যপ্রণালি-বিধি সম্পর্কিত | হাফিজ উদ্দিন আহমদ (ভোলা-৩) |
| পিটিশন | হাফিজ উদ্দিন আহমদ (ভোলা-৩) |
| বিশেষ অধিকার সম্পর্কিত | হাফিজ উদ্দিন আহমদ (ভোলা-৩) |
| অনুমিত হিসাব সম্পর্কিত | রেজা কিবরিয়া (হবিগঞ্জ-১) |

| সড়ক পরিবহন ও সেতু | রকিবুল ইসলাম (খুলনা-৩) |

| তথ্য ও সম্প্রচার | মো. আমানউল্লাহ আমান (ঢাকা-২) |

| বিজ্ঞান ও প্রযুক্তি | এম. রুহুল কুদ্দুস তালুকদার দুলু (নাটোর-২) |
| নৌ-পরিবহন | জয়নুল আবদিন ফারুক (নোয়াখালী-২) |
| সংস্কৃতি বিষয়ক | বরকত উল্লাহ বুলু (নোয়াখালী-৩) |
