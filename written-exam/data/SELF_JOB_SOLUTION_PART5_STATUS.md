⚠️ **সমান্তরাল সেশন সতর্কতা:** Selim একই সময়ে একাধিক Claude সেশন/ডিভাইস থেকে এই রেপোতে কাজ করেন। এই ফাইল পড়ার পরপরই `git fetch` + `git log HEAD..origin/main` চেক করে নিশ্চিত হও যে নতুন কোনো commit আসেনি যা এখানে এখনো প্রতিফলিত হয়নি — নাহলে "বাকি আছে" তালিকায় এমন এন্ট্রি দেখানো হতে পারে যা ইতিমধ্যে অন্য সেশন যোগ করে ফেলেছে।

⚠️ **সতর্কতা:** `job-solution.js`-এ দুই ধরনের JS object syntax মিশে আছে:
- পুরনো অংশ: unquoted keys — `{ id: "...", examId: "...", ... }`
- নতুন অংশ: quoted keys — `{"id": "...", "examId": "...", ...}`

শুধু `"examId":` প্যাটার্ন দিয়ে গ্রেপ করলে পুরনো অংশ বাদ পড়ে যাবে (ভুল করে "মাত্র ৫৭টা আছে" মনে হবে, আসলে ৮৯টা ছিল)। সবসময় **দুটো প্যাটার্নই** চেক করতে হবে:
```bash
grep -oE 'examId["\x27]?\s*:\s*["\x27][^"\x27]+["\x27]' job-solution.js | sort -u
```
